┌─ how it was built // each step answered the question before it

  1. ACan simple local rules make a video?memoryless rules · Life-like rules · lookup tablesExact lookup-table rules replay short clips, but the tables are far larger than the recordings. Memoryless Life-like rules cannot express direction: the best ones only erode the picture. record: CHECKPOINT_01 · CHECKPOINT_07
  2. BWhat if cells have memory and several updates per frame?exact SAT searchHidden bits per cell help an exact SAT search find rules on short clips. Exact rules reached 10 frames; 20–40 frames timed out, and the rules were larger than every recording baseline. record: CHECKPOINT_02 · CHECKPOINT_03 · CHECKPOINT_04
  3. CCan we search for small rules directly?circuit synthesis · CGP · DiffLogic · decision listsSmall circuits won only on synthetic controls, and soft DiffLogic rules did not harden well. CGP circuits of 3–10 gates follow coarse shape on 60 frames but not motion: 0/32 motion-aware runs followed it (late “motion” was edge flicker). Explicit decision lists reach ~0.10 error at best. record: CHECKPOINT_05 · CHECKPOINT_06 · CHECKPOINT_07 · CHECKPOINT_08 · CHECKPOINT_12
  4. DWhat if the state is continuous?Neural CAA 10,320-parameter neural CA replays a short real action from the first frame, where CGP passes no stage. More training and a contour loss cleaned the outlines (error 0.0040 on 56 frames, 0.0134 on 60); 120 frames pass, 240 fail, and smaller models fail. The files are larger than recordings: this is not compression. record: CHECKPOINT_09 · CHECKPOINT_10 · CHECKPOINT_11
  5. EWhat if the rule changes with the scene?phases on an external schedule, state carried over4–6 phases fixed the 240-frame transition interval (error 0.019–0.028, vs 0.045 for a same-size single rule). Automatic segmentation was never better than equal spacing. record: CHECKPOINT_12
  6. FHow do we keep long replays stable?training-only state noise · export checksChained phase rules amplified tiny numerical differences between training and replay; without noise the whole song diverged after ~1,080 frames. Training-only state noise (σ = 0.02), with chunk states carried by the replay's own arithmetic, made replay equal training; the whole song (6,572 frames) then passed every check. Each export is replayed independently (numpy, Node, browser) and checked before it becomes the demo. record: CHECKPOINT_12 · CAMPAIGN_13
