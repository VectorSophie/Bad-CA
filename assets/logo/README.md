# Logo and icons

**Files:**
- `bad-ca-logo.png`: README logo (pixel mark + "Bad CA!!").
- `bad-ca-mark.png`: the mark alone.
- `favicon-16.png`, `favicon-32.png`, `icon-180.png`, `icon-512.png`: icons. `ui/static/favicon.png` is the 32 px icon.
- `check_light_dark.png`: preview on light and dark backgrounds.

All files are regenerated by `tools/make_logo.py`.

## Source and transformation (no generated imagery)
- **Source:** `BadApple!!.mp4` from a local clone of `C-mykk/Bad-Apple-Starter`, sha256
  `d8f21232313506da4f8d631ca289793bcf2f0a33440d68ccb02f4ac52e963cd0`, 480×360, 30 fps. The script checks the hash.
- **Frame:** decoded frame **310**, t = 10.333 s. It shows the girl's profile with an open mouth and the apple, with its
  stem, at her lips: the moment before the bite.
- **How it was chosen:** decoded frames 260–344 were compared (2-frame steps, cropped). Frames 318–326 blur as the apple
  meets the lips, so 310 reads best. The falling apple (370–460) was checked too; it shows no visible bite mark.
- **Mark:** a 200×150 crop at (110, 110)–(310, 260), the same 4:3 aspect as the source and not stretched, then:
  1. PIL `L` luma;
  2. box downsample to an 80×60 grid;
  3. threshold 128;
  4. nearest-neighbour upscale ×4.
- **Icons:** a 132×132 crop at (158, 150)–(290, 282) around the apple and mouth, a 16×16 grid (16 / 32 px) or 32×32
  grid (180 / 512 px), threshold 128, nearest upscale. A smaller crop is used so the apple still reads at 16 px; the
  icon is not the whole frame shrunk.
- **Title font:** Departure Mono (SIL OFL 1.1, `ui/static/fonts/OFL-departuremono.txt`).
